# Text Classification Annotation Project

## Project Overview
This project demonstrates manual text classification and data annotation using four categories.

## Annotation Categories
- Positive
- Negative
- Neutral
- Complaint

## Dataset
- Total records: 10
- Format: CSV
- Annotation type: Text classification

## Annotation Guidelines
Each sentence is assigned one primary label based on its meaning and intent.

## Skills Demonstrated
- Text classification
- Data labeling
- Annotation guidelines
- CSV dataset preparation
- Data quality checking

## Files
- `dataset.csv` — Annotated dataset
- `annotation_guidelines.md` — Annotation rules

## Project Objective
To demonstrate practical understanding of structured text annotation and consistent labeling.
